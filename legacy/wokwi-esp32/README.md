# Simulacao antiga — ESP32 / Wokwi

Esta pasta preserva os arquivos utilizados na primeira etapa de prototipacao virtual da HomeWise com ESP32 no Wokwi.

O controlador oficial do prototipo passou a ser o WEMOS D1 R1 com ESP8266, pois e o hardware fisico disponivel para os testes e para a apresentacao.

Os arquivos desta pasta servem apenas como registro historico da etapa de simulacao e nao representam mais o alvo de compilacao principal do projeto.
